This is a learning repo. 

It contains a lot of working-code which is unrelated. 

There are 2 main agents here
1. agents/gmail-agent: Connects with your gmail account (gmail client implementation), identifies unread email, categorieses them into ignore, summary and respond. It will also create a draft email in your inbox.
2. src/02-agentic-rag-core: Baseline QA agent that lets you query a PDF datafile. Simply put your file under data/ and query it using the notebook.
